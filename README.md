# 電子廢物寵物（ NUCLEO-G474RE 期中專題）
桌面上的小寵物 不吃飼料只吃電
## 1. 在每天都要面對程式錯誤、反覆除錯的工程師桌上，總是缺少一點樂趣。
因此，我決定製作一隻名叫「kitty」的桌面小寵物，陪伴使用者度過無聊的寫程式時光。
kitty雖然只是紙板做成的小生物，卻擁有自己的個性！
它不能幫你修程式，但至少能陪你一起崩潰。

## 2. 紅藍綠燈是寵物不同時候的眼睛
      馬達是寵物搖晃的尾巴

## 3. 按按鈕可以更換藍綠眼睛 按另一個按鈕可以切換警急模式變紅眼睛停止搖尾巴 可開啟對話功能與他互動

## 4. 用到的技術：第 3 ～ 7 週勾選表（同投影片）
## 5. 腳位:LED 紅 PA0、綠 PA1、藍 PA4
      馬達 PB3~PB6
      按鈕1 PC0(換眼色)pull up、按鈕3 PA10(EXTI,緊急)pull up
      UART:USART2 PA2/PA3,115200 8N1,透過 ST-LINK 虛擬 COM 埠

## 6. 建置與執行：開發環境
      硬體:28BYJ-48 + ULN2003、藍/綠/紅 LED(眼睛)、2 顆按鈕、麵包板。
      腳位:LED 紅 PA0、綠 PA1、藍 PA4;馬達 PB3~PB6;
      按鈕1 PC0(換眼色)pull up、按鈕3 PA10(EXTI,緊急)pull up。
      UART:USART2 PA2/PA3,115200 8N1,透過 ST-LINK 虛擬 COM 埠）
